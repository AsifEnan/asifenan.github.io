1st: The first function read_data_keyword

Using the function I created in Task2 to read in the data. it essentially reads a raw gustometer xlsx by scanning for the row containing “PRESENTATION”, treating it as the header, and extracting only the valid data rows below it (stopping at the first fully empty row). handles the messy metadata info at the top.

#General function to read the excel data into R
#Creating the function (has 3 parameters)

read_data_keyword <- function(file_path, keyword = "PRESENTATION", sheet = 1) {
  # Reading the entire sheet first
  raw_data <- read_excel(file_path, sheet = sheet, col_names = FALSE)
  
  # Identifying the starting row (where keyword is found)
  start_row <- which(apply(raw_data, 1, function(row) any(row == keyword)))[1]
  #defensive coding
  if (is.na(start_row)) {
    stop("Keyword not found in the sheet.")
  }
  
  # Extracting headers from the keyword row
  header_row <- as.character(unlist(raw_data[start_row, ]))
  
  # Finding the last non-empty column name
  last_col <- max(which(!(is.na(header_row) | header_row == "")))
  
  # Trimming the header and data columns to only valid headers
  headers <- header_row[1:last_col]
  
  # Getting all data rows starting from the next row after header row
  data_rows <- raw_data[(start_row + 1):nrow(raw_data), 1:last_col]
  
  # Finding first empty row (all cells are NA or "")
  end_row_relative <- which(apply(data_rows, 1, function(row) all(is.na(row) | row == "")))[1]
  
  if (!is.na(end_row_relative)) {
    # Limit to rows before the empty one
    data_rows <- data_rows[1:(end_row_relative - 1), ]
  }
  
  # Set column names
  colnames(data_rows) <- headers
  
  return(data_rows)
}

2nd: Function for reading the excel files

This function runs the above function, read_data_keyword on every .xlsx in a folder and returns a named list, one element per file. This let you load all mice gustometer data files at once.

import_all_xlsx_files <- function(folder_path, keyword = "PRESENTATION") {
  files <- list.files(path = folder_path, pattern = "\\.xlsx$", full.names = TRUE)
  
  # Applying cleaning function to each file and storing in a named list
  data_list <- lapply(files, function(file) {
    tryCatch({
      read_data_keyword(file, keyword = keyword)
    }, error = function(e) {
      warning(paste("Skipping file:", file, "-", e$message))
      NULL
    })
  })
  
  # Naming each element by filename
  names(data_list) <- basename(files)
  
  return(data_list)
}

Be mindful that the output of the above function generates a list (a named list of dataframes as its elements)

What the above 2 function does

  • read_data_keyword : takes a single file path, finds the keyword row, extracts clean data, returns one dataframe.

  • import_all_xlsx_files : takes a folder path, finds all .xlsx files in it, loops through them calling read_data_keyword on each, returns a named list of dataframes.

3rd: Function for Calculating the LickRatio

The key metric is the Lick Ratio:

Lick Ratio = Licks to taste compound ÷ Licks to water

We’ll be constructing a function that does this, but also keeping some other conditions in mind. In the function we will follow these steps.

Step 1: Check licks for water first (since it’s the denominator): Look at the raw lick vector for 0mM. If fewer than 2 trials have non-zero licks → drop the entire mouse. No point going further.

Step 2: Check licks of the other concentrations (30mM, 1mM, 3mM, 10mM): For each concentration, we will look at the raw lick vector and apply this rule:

  • If 2 or more trials have non-zero licks → keep. (e.g. [1, 0, 0, 1, 0, 0])

  • If only 1 trial has non-zero licks, BUT that single value is ≥ 10 → also keep. (e.g. [15, 0, 0, 0, 0, 0] passes, [9, 0, 0, 0, 0, 0] does not)

  • If only 1 trial has non-zero licks AND that value is < 10 → drop the entire mouse.

  • If zero trials have non-zero licks → drop the entire mouse.

And in all “drop” cases, we’re removing the whole mouse, not just that concentration.

get_lick_ratios <- function(data, mouse_id=1, genotype_label= "No genotype specified") {
  
  # Ensuring LICKS is numeric up front
  data <- data %>% mutate(LICKS = as.numeric(LICKS),
                          CONCENTRATION = trimws(as.character(CONCENTRATION))
                          )
  
  #Step 1: Raw lick vector for Water
  water_trials <- data %>%
    filter(CONCENTRATION %in% c("0", "0mM")) %>%
    pull(LICKS)
  
  n_nonzero_water <- sum(water_trials > 0, na.rm = TRUE)
  
  if (n_nonzero_water < 2) {
    message(paste("Mouse", mouse_id, "(", genotype_label, ") excluded: fewer than 2 non-zero water trials."))
    return(NULL)
  }
  
  #Step 2: Raw lick vector for non-water concentrations
  taste_concs <- data %>%
    filter(!CONCENTRATION %in% c("0", "0mM")) %>%
    pull(CONCENTRATION) %>%
    unique()
  
  for (conc in taste_concs) {
    conc_trials <- data %>%
      filter(CONCENTRATION == conc) %>%
      pull(LICKS)
   #we keep only the values that are both non-NA and greater than zero     
    nonzero_vals  <- conc_trials[!is.na(conc_trials) & conc_trials > 0]
    n_nonzero     <- length(nonzero_vals)
    
    exclude <- FALSE
    
    if (n_nonzero == 0) {
      # No licking at all at this concentration
      exclude <- TRUE
    } else if (n_nonzero == 1) {
      # Only one non-zero trial: keep only if that single value >= 10
      if (nonzero_vals[1] < 10) {
        exclude <- TRUE
      }
    }
    # n_nonzero >= 2: always keep, no action needed
    
    if (exclude) {
      message(paste("Mouse", mouse_id, "(", genotype_label, ") excluded: concentration", conc,
                    "failed the reliability check (non-zero trials:", n_nonzero,
                    "| values:", paste(nonzero_vals, collapse = ", "), ")."))
      return(NULL)
    }
  }
  
  # Once a mouse passed all checks: compute LickRatio
  data %>%
    group_by(CONCENTRATION) %>%
    summarise(total_licks = sum(LICKS, na.rm = TRUE), .groups = "drop") %>%
    mutate(
      CONCENTRATION = as.character(CONCENTRATION),
      water_licks   = total_licks[CONCENTRATION %in% c("0", "0mM")],
      # water_licks is guaranteed > 0 by Step 1, so LickRatio will never be Inf or NaN
      LickRatio     = total_licks / water_licks,
      CONCENTRATION = as.factor(CONCENTRATION)
    ) %>%
    filter(CONCENTRATION %in% c("1mM", "3mM", "10mM", "30mM")) %>%
    mutate(Mouse = mouse_id, Genotype = genotype_label)
}

4th: Using the get_lick_ratios() function on many datasets using map2()

Now, Applying the get_licks_ratios() function, on one data frame at a time is inefficient, and if we have 100 or more than 100 data sets, it will take a lot of time.

We need to find a way to apply this function to many data sets in one go. That is what the code will do. a way of applying a function to every element of a list, one at a time, without writing a for loop.

Step 4:

Apply get_lick_ratios to every mouse in one pass map2 pairs each dataframe with its position index, from that index we look up the right genotype and mouse_id

results_list <- map2(
  .x = datasets,          # the dataframe for this mouse
  .y = seq_along(datasets), # its position: 1, 2, 3, ... 200
  .f = ~ get_lick_ratios(
    data           = .x,
    mouse_id       = mouse_ids[.y],
    genotype_label = genotypes[.y]
  )
)
